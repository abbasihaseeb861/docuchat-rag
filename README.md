# 🧬 DocuChat-RAG - Chat with Your Research Papers

A smart AI chatbot that lets you upload any scientific PDF and ask questions from it. Built with LangChain and Streamlit.

### ✨ Features
- 📄 Upload any PDF (Research Paper, Thesis, Book)
- 🤖 AI-powered Question Answering
- 🔍 Finds relevant paragraphs from your document
- Free Embeddings - No API Key needed

### 🛠️ Tech Stack
- Python
- Streamlit
- LangChain
- ChromaDB (Vector Database)
- HuggingFace Embeddings (all-MiniLM-L6-v2)
